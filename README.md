# Portfolio — Afiq Andico Pangimpian

Konsolidasi portofolio riset, AI/ML, dan web (2026-09-06). Setiap proyek berada di
subfolder tersendiri dengan README dan lisensinya masing-masing.

## Isi Repo

| Proyek | Bidang | Teknologi | Ringkasan |
|---|---|---|---|
| [signbridge-ai/](signbridge-ai/) | Computer Vision / AI | Python, PyTorch | Penerjemah bahasa isyarat BISINDO real-time |
| [itb-stkom-research/](itb-stkom-research/) | Data Science | Python, Orange | Optimasi manajemen kampus (marketing, SDM, operasional) via klasifikasi |
| [inji-cho/](inji-cho/) | Web / GIS | Vanilla JS, Leaflet, Vite | Katalog kuil (Hidden Shrine Catalog) |
| [anotherwaltz-site/](anotherwaltz-site/) | Web / Studio | Astro, Tailwind | Situs art collective Bali (anotherwaltz.id) |
| [lstm-partial-reset/](lstm-partial-reset/) | Deep Learning | Python, PyTorch | 4 eksperimen periodic partial reset pada LSTM/GRU (concept drift, saham, PM2.5, stres) |
| [ml-business-portfolio/](ml-business-portfolio/) | ML Bisnis | Python, XGBoost, Prophet, Redis | Fraud detection, analitik kafe (RFM), dan streaming sentiment |
| [portfolio-showcase/](portfolio-showcase/) | Showcase | C, Python, Embedded | Kumpulan demo ML, security, web, embedded & GIS |
