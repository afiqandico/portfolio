## Stack

- **Framework**: [Astro 4](https://astro.build) (static-first, SEO-friendly)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com) + [daisyUI 4](https://daisyui.com) — custom `waltz` theme (warm earthy)
- **Fonts**: Fraunces (serif display) + Inter (body) + JetBrains Mono (code)
- **Aesthetic**: Editorial, warm cream/maroon, breathing whitespace
